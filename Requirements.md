# summary 
This project is a replacement / upgrade for https://fallbrookhastalent.org/
I want to change the theam to be more light with a fun event vibe the old site is a little too "night club" feeling.
the site will be renamed with a new domain northcountyhastalent.com (already purchased)

# site elements

## Performers
photos and bio for performers with links to their social / web sites

## Tickets
basic info for tickets - the actual ticket transaction will be handled by tixfox.co

## Sponsors
photos and bio for sponsors already committed to the event
a way to request to become a sponsor (email form)

## Past events
this will be a new page showing a photo gallery for each previous event, currently there will only be one "2025 Fallbrook has talent"

## Audition to perform
this will be a new page with basic performer requirements (pending copy you can make up a placeholder for now, but it will be basic info like name / band name, still photo, social media / website links, breif bio, and a link to a publicly accessable video (youtube) of them performing.) this info will be emailed (email destination TBD)
